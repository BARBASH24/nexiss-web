# Решение проблемы с Google OAuth для России

## Проблема
Google Cloud Console не позволяет выбрать Россию при создании проекта.

## Решения:

### Вариант 1: Использовать VPN (Рекомендуется)

1. Подключитесь к VPN (например, США, Германия, Польша)
2. Откройте https://console.cloud.google.com/ через VPN
3. Создайте проект - теперь можно выбрать другую страну
4. Настройте OAuth как обычно (инструкция в GOOGLE_OAUTH_SETUP.md)
5. После настройки VPN можно отключить - credentials будут работать

### Вариант 2: Использовать существующий проект

Если у вас уже есть Google Cloud проект (созданный раньше или в другой стране):
1. Используйте его
2. Добавьте OAuth credentials
3. Всё будет работать

### Вариант 3: Попросить коллегу из другой страны

1. Попросите коллегу создать проект в Google Cloud Console
2. Он добавит вас как владельца проекта
3. Вы сможете создать OAuth credentials

### Вариант 4: Использовать альтернативные OAuth провайдеры

Я могу добавить вход через:
- **GitHub** (работает из России без проблем)
- **Yandex ID** (российский сервис)
- **VK ID** (российский сервис)
- **Mail.ru** (российский сервис)

Хотите, чтобы я добавил один из этих вариантов?

### Вариант 5: Отключить Google OAuth

Если OAuth не критичен, можно:
1. Просто использовать обычный вход через email/пароль (уже работает)
2. Убрать кнопку Google с интерфейса
3. Добавить OAuth позже, когда появится возможность

## Что я рекомендую:

### Для разработки:
Используйте обычный вход (email/пароль) - он полностью работает

### Для production:
Добавьте **GitHub OAuth** или **Yandex ID** - они работают из России без проблем

## Хотите, чтобы я добавил GitHub OAuth?

GitHub OAuth работает отлично из России и настраивается проще:
1. Заходите на https://github.com/settings/developers
2. Создаете OAuth App
3. Получаете Client ID и Secret
4. Всё работает
