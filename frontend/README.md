# nexiss - Frontend

Фронтенд приложение для nexiss, построенное с использованием React, TypeScript, Vite и Tailwind CSS.

## Архитектура

Проект использует **Feature-Sliced Design (FSD)** архитектуру:

```
src/
├── app/          # Инициализация приложения, глобальные стили
├── pages/        # Страницы приложения
├── widgets/      # Крупные самостоятельные блоки UI
└── services/     # API и бизнес-логика
```

## Технологии

- **React 18** - UI библиотека
- **TypeScript** - Типизация
- **Vite** - Сборщик и dev-сервер
- **Tailwind CSS** - Utility-first CSS фреймворк
- **React Router** - Маршрутизация

## Установка

```bash
npm install
```

## Разработка

```bash
npm run dev
```

Приложение будет доступно по адресу: http://localhost:5173

## Сборка

```bash
npm run build
```

## Структура проекта

- `src/app/` - Точка входа, глобальные стили, провайдеры
- `src/pages/` - Компоненты страниц (HomePage, AboutPage, и т.д.)
- `src/widgets/` - Переиспользуемые виджеты (Header, Footer, Hero, и т.д.)
- `src/services/` - API клиенты и сервисы
- `public/` - Статические файлы (favicon, logo)

## Дизайн

Сайт использует брутальный минималистичный дизайн:
- Строгая черно-белая палитра
- Огромная типографика
- Геометрические формы
