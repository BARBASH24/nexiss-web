# nexiss - Landing Page

Лендинг страница для nexiss - AI-Powered IDE для разработки.

## 🚀 Быстрый старт

```bash
cd frontend
npm install
npm run dev
```

Откройте [http://localhost:5173](http://localhost:5173)

## 📦 Технологии

- **React 18** - UI библиотека
- **TypeScript** - Типизация
- **Vite** - Сборщик
- **Tailwind CSS** - Стилизация
- **React Router** - Роутинг

## 🏗️ Структура проекта

```
frontend/
├── src/
│   ├── app/           # Главный App компонент
│   ├── pages/         # Страницы (Home, About, Features, etc.)
│   ├── widgets/       # Переиспользуемые виджеты
│   └── services/      # API сервисы
├── public/            # Статические файлы
└── index.html         # Точка входа
```

## 🎨 Страницы

- **Home** - Главная страница с Hero, Features, Testimonials
- **Features** - Детальное описание возможностей
- **Pricing** - Тарифные планы
- **Docs** - Документация
- **About** - О проекте
- **Contact** - Контакты

## 📝 Разработка

```bash
# Установка зависимостей
npm install

# Запуск dev сервера
npm run dev

# Сборка для продакшена
npm run build

# Превью продакшен сборки
npm run preview
```
